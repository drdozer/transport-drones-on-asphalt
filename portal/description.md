# Transport Drones on Asphalt

Transport drones only drive on their own roads — until now. This mod enables transport drones to drive on road tiles provided by a range of other mods.

## Supported surfaces

| Partner mod | Tiles |
|---|---|
| Asphalt Roads (or AsphaltRoadsPatched ≥ 1.5.0) | the full generated `Arci-` set (66 tiles incl. directional variants) |
| PyIndustry ≥ 3.1.6 | `py-asphalt` |
| water-ford ≥ 1.1.0 | cobblestone ford, cobblestone path |
| Space Exploration | all Asphalt Roads tiles become placeable in space |

## Mod compatibility

If you would like support added for another mod's road tiles, open a new discussion on this mod's page.

## Requirements

- Factorio **2.1** (Space Age optional)
- **Transport Drones ≥ 2.1.4** — the official 2.1 line; no fork support
- Surface partners per the table, all optional
